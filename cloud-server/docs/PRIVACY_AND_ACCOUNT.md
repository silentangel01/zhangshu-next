# 章枢云隐私与账户说明

## 本地优先原则

章枢是本地优先的写作工具。你的作品数据始终保存在本地设备上。云备份是可选的附加功能，不会因为云账户的变动而删除本地数据。

- **未启用云备份的作品**：仅存在于你的本地设备，章枢云端不保存任何副本。
- **已启用云备份的作品**：备份 zip 会上传到章枢云存储（OSS），本地副本始终保留。

## 云端保存哪些数据

当你注册并使用章枢云账户时，云端会保存以下数据：

| 数据类型 | 说明 |
|---|---|
| 账户邮箱 | 用于登录和身份标识 |
| 显示名称 | 可选，用于界面展示 |
| 密码哈希 | bcrypt 加密存储，不保存明文密码 |
| 云项目 | 你启用了云备份的项目 ID 和标题 |
| 备份 zip | 加密上传到 OSS 的项目备份文件 |
| 备份元数据 | 文件名、大小、校验和、上传时间、状态 |
| 审计日志 | 关键操作记录（登录、密码修改、数据导出、删除请求），仅记录脱敏信息 |
| 会话信息 | refresh token（哈希）、user_agent、client_ip（用于安全管理） |

## 云端不保存哪些数据

| 数据类型 | 说明 |
|---|---|
| 本地未启用云备份的作品 | 完全存在于你的本地设备 |
| AI API Key | 仅保存在本地数据库（加密存储） |
| OSS AccessKey | 仅由服务端使用，不返回给客户端 |
| 章节正文原文 | 除非你主动启用了云备份 |

## 如何导出云数据

通过 **应用设置 > 账户与隐私 > 导出 JSON** 可以下载你的账户元数据。

导出内容包含：
- 账户基本信息（ID、邮箱、显示名、注册时间）
- 云项目列表（ID、标题、创建时间）
- 备份元数据（文件名、大小、校验和、状态、时间）
- 当前使用量和配额

导出内容**不包含**：
- 密码哈希
- refresh token
- OSS AccessKey
- presigned URL 完整签名
- 备份 zip 文件内容（如需下载备份，请通过已有的备份恢复流程逐个下载）

## 如何修改密码

通过 **应用设置 > 账户与隐私 > 修改密码**。

修改密码后：
- 所有设备的 refresh token 将被撤销
- 所有设备都需要重新登录

## 如何退出所有设备

通过 **应用设置 > 账户与隐私 > 退出所有设备**。

操作后：
- 所有已登录设备的会话将被撤销
- 包括当前设备在内的所有设备都需要重新登录

## 如何删除云账号和备份

删除云账号采用**两阶段确认**，防止误操作：

### 第一阶段：发起删除请求
1. 在 **应用设置 > 账户与隐私 > 删除账号** 输入密码
2. 系统验证密码后返回影响范围：
   - 将删除的项目数量
   - 将删除的备份数量
   - 将释放的存储空间

### 第二阶段：确认删除
1. 输入指定的确认文本（`DELETE MY CLOUD DATA`）
2. 确认后系统执行：
   - 撤销所有 refresh token
   - 删除 OSS 上的所有备份文件
   - 软删除云项目和备份记录
   - 匿名化用户信息：
     - 邮箱变为 `deleted+<user_id>@deleted.local`
     - 显示名变为 "已删除用户"
     - 密码替换为不可登录的随机值
     - 账户标记为未激活

### 删除边界

- **本地作品不受影响**：删除云账号不会删除你本地的任何作品数据。
- **OSS 删除失败处理**：如果部分 OSS 对象删除失败，系统会如实报告，不会声称数据已完全删除。管理员需要后续手动处理。
- **审计日志保留**：出于安全审计目的，操作日志会在删除后保留一段时间。
- **不可恢复**：匿名化后无法恢复原始账户信息。

## 滥用防护

为了保护所有用户的服务质量，章枢云实施了以下限制：

| 限制 | 说明 |
|---|---|
| 登录频率 | 同一 IP + 邮箱组合在时间窗口内有尝试次数限制 |
| 注册频率 | 同一 IP 在时间窗口内有注册次数限制 |
| 备份频率 | 每小时备份初始化次数有上限 |
| 存储配额 | 每个用户的总存储空间有上限 |
| 备份数量 | 每个用户的备份文件数量有上限 |
| 单文件大小 | 单个备份 zip 文件大小有上限 |

所有限制在 **应用设置 > 使用量与配额** 中可查看当前使用情况。

## 安全实践

- 密码使用 bcrypt 加密存储（可配置 rounds）
- refresh token 使用安全随机生成，哈希后存储
- API 访问使用 JWT bearer token
- 所有 API 通信使用 HTTPS（生产环境强制）
- 审计日志记录关键操作，但只保存脱敏信息（如 IP、request_id，不保存密码或 token 明文）
- 限流 key 使用 SHA-256 哈希，不存储完整邮箱明文

## 联系管理员

如果你遇到以下问题，请联系管理员：
- 云账户被锁定（频率限制）
- OSS 删除失败导致数据残留
- 需要恢复已删除的账户数据（可能不可行）
- 安全相关问题
