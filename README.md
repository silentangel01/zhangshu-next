\# Zhangshu Next



Zhangshu Next is the next-generation architecture prototype for the Zhangshu web novel writing software.



\## Tech Stack



\- Frontend: Vue 3 + TypeScript + Vite

\- Backend: Python + FastAPI + Pydantic

\- Local Database: SQLite

\- Desktop Shell: Tauri, planned for later phases

\- Search: SQLite FTS5, planned

\- AI/RAG: planned
