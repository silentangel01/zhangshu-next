## 五、部署方式

构建成功后，将 `dist/` 内容上传到服务器。

推荐方式一：使用 `scp`

```powershell
ssh root@121.40.247.143 "mkdir -p /tmp/zhangshu-website-dist"
scp -r F:\zhangshu\website\dist\* root@121.40.247.143:/tmp/zhangshu-website-dist/
```

然后在服务器执行：

```bash
sudo mkdir -p /var/www/zhangshu-website
sudo rm -rf /var/www/zhangshu-website/*
sudo cp -r /tmp/zhangshu-website-dist/* /var/www/zhangshu-website/
sudo chown -R www-data:www-data /var/www/zhangshu-website || sudo chown -R nginx:nginx /var/www/zhangshu-website || true
```

推荐方式二：如果 scp 在 Windows 下处理路径不方便，可以先压缩：

```powershell
cd F:\zhangshu\website
Compress-Archive -Path .\dist\* -DestinationPath .\zhangshu-website-dist.zip -Force
scp .\zhangshu-website-dist.zip root@121.40.247.143:/tmp/zhangshu-website-dist.zip
```

然后在服务器解压：

```bash
sudo mkdir -p /var/www/zhangshu-website
sudo rm -rf /var/www/zhangshu-website/*
sudo unzip -o /tmp/zhangshu-website-dist.zip -d /var/www/zhangshu-website
sudo chown -R www-data:www-data /var/www/zhangshu-website || sudo chown -R nginx:nginx /var/www/zhangshu-website || true
```

注意：

* 只允许清空 `/var/www/zhangshu-website/`。
* 不允许清空 `/var/www/`。
* 不允许清空其他目录。

基础 HTTP 配置先使用：

```nginx

    listen 80;
    listen [::]:80;
    server_name zhangshu.xin www.zhangshu.xin;

    root /var/www/zhangshu-website;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;

}
```

配置后执行：

```bash

sudo systemctl reload nginx
```

只有 `nginx -t` 成功后，才允许 reload。
