# 章枢 UI 回归检查清单

本文档用于 UI 改造后的测试构建前检查。检查目标是确认界面稳定、中文显示正常、主要流程可用；不包含新增功能验收。

## 页面检查

每个页面均需检查：

- 视觉风格与“墨青纸白”主题一致。
- 无过量解释文字。
- 主操作清晰。
- 空状态清楚。
- 加载与错误状态可接受。
- 页面整体无全局横向滚动条。
- 简体中文显示正常。
- 浏览器控制台无明显错误。

### 1. 项目列表页

- [ ] 项目卡片或列表信息可扫读。
- [ ] 新建项目入口清楚。
- [ ] 空项目状态清楚。
- [ ] 错误提示不暴露技术堆栈。

### 2. 写作工作区

- [ ] 三栏布局稳定。
- [ ] 进入项目后能快速开始写作。
- [ ] 顶部工具与编辑区不拥挤。
- [ ] 当前章节状态恢复正常。

### 3. 左侧章节树

- [ ] 仅承载项目标题、分卷和章节树。
- [ ] 当前章节高亮清楚且不刺眼。
- [ ] 新建分卷、新建章节入口位置合理。
- [ ] 折叠后仍可恢复。

### 4. 中心编辑器

- [ ] 当前章节标题只出现必要位置。
- [ ] 编辑工具栏紧凑。
- [ ] 状态行保持单行轻量。
- [ ] 正文输入区宽度适合长时间写作。

### 5. 右侧写作辅助面板

- [ ] Tab 标签简短。
- [ ] 仅展示当前章节相关摘要。
- [ ] 空状态简短可行动。
- [ ] 折叠状态可恢复。

### 6. 大纲页

- [ ] 顶部标题、返回与主操作位置一致。
- [ ] 左侧树层级清楚。
- [ ] 选中条目明显。
- [ ] 详情表单分组清晰。
- [ ] 关联资料区位置稳定。

### 7. 人物页

- [ ] 人物列表紧凑可扫读。
- [ ] 详情编辑不像数据库记录。
- [ ] 类型、状态、重要程度标签一致。
- [ ] 删除操作与普通保存操作分离。

### 8. 设定页

- [ ] 设定类型和状态可见。
- [ ] 长文本字段可读。
- [ ] 列表、详情、关联资料布局一致。
- [ ] 空状态简短。

### 9. 伏笔页

- [ ] 生命周期状态醒目但克制。
- [ ] 埋设、推进、回收字段分组清楚。
- [ ] 列表项信息不过载。
- [ ] 危险操作位置明确。

### 10. 时间轴页

- [ ] 工具栏按工具、视图、显示、操作分组。
- [ ] 轨道列表可扫读。
- [ ] 节点选中态清楚。
- [ ] 边线选中态清楚。
- [ ] 详情面板打开后边线不偏移。

### 11. 关系图页

- [ ] 工具栏按工具、视图、显示、操作分组。
- [ ] 网格、吸附、清爽模式语言一致。
- [ ] 节点与关系选中态清楚。
- [ ] 右键菜单样式一致。
- [ ] Inspector 仅显示当前选中对象。
- [ ] 容器尺寸变化后边线对齐。

### 12. 统计页

- [ ] 如页面存在，检查今日字数、本周字数、本月字数、今日写作时长、连续写作、平均速度标签。
- [ ] 热力图颜色低噪。
- [ ] 小时图和章节排行不无限拉伸。
- [ ] 不过度强调增删字调试字段。

### 13. 审阅检查页

- [ ] 检查范围控件清楚。
- [ ] “开始检查”是明确主操作。
- [ ] 词库、导入词库、导出词库入口清楚。
- [ ] 检查结果卡片可读。
- [ ] 打开章节入口位置稳定。

### 14. 导入导出页

- [ ] 文件选择区清楚。
- [ ] 预览步骤不会误导为已写入。
- [ ] 确认导入按钮仅在预览后出现。
- [ ] 导入报告摘要可读。
- [ ] 成功与失败状态清楚。

### 15. 备份恢复页

- [ ] 导出作品、导出项目备份、从备份恢复项目职责分明。
- [ ] 恢复说明强调不会覆盖原项目。
- [ ] 备份文件选择状态可见。
- [ ] 恢复报告计数和警告可读。

### 16. 搜索页

- [ ] 搜索输入突出。
- [ ] 搜索结果按章节清晰展示。
- [ ] 点击结果可打开章节。
- [ ] 未搜索与无结果状态简短。

## 视口检查

需要检查以下窗口或浏览器视口：

- [ ] 1280×720
- [ ] 1366×768
- [ ] 1440×900
- [ ] 1920×1080
- [ ] 浏览器缩放 125%

### 重点场景

- [ ] 1280×720 下写作页仍可输入正文。
- [ ] 右侧写作辅助面板可折叠。
- [ ] 左侧章节树可折叠。
- [ ] 编辑器不会被压到难以写作。
- [ ] 宽屏下正文区域不会无限变宽。
- [ ] 时间轴页调整窗口后边线仍对齐。
- [ ] 关系图页调整窗口后边线仍对齐。
- [ ] 工具页在宽屏下不会无限拉伸。

## 构建前检查记录

- [ ] `npx vue-tsc --noEmit -p tsconfig.app.json`
- [ ] `npm run build`
- [ ] 后端导入检查：`python -c "import app.main; print('backend import ok')"`

## 备注

- 若构建或开发服务器因本地权限、杀毒或沙箱限制失败，应记录具体错误信息。
- 若无法进行人工视口测试，应在测试构建说明中标记为未完成项。
