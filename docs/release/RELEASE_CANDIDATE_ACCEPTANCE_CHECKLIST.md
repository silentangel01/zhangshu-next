# 章枢 Release Candidate 发布前验收清单

## 执行规则

1. 本清单用于章枢正式发布前的总体验收。
2. 所有 **P0** 项必须 **Pass**，否则阻断发布。
3. 所有 **P1** 项原则上必须 Pass；若未通过，必须记录风险并获得用户确认后标记 **Accepted Risk** 方可发布。
4. **P2** 项 Fail 可记录为后续改进，不阻断发布。
5. 不得使用真实用户隐私数据做破坏性测试。
6. 删除云账号、恢复数据库、清空备份等高风险测试**必须使用测试账号、测试项目、测试 Bucket 或本地测试环境**。
7. 验收中发现 bug 时，本轮只记录到"备注"栏，不直接修复代码。
8. 状态栏只允许填写：`Pass` / `Fail` / `Blocked` / `N/A` / `Accepted Risk`。

## 2. 发布阻断标准

| 级别 | 含义 | 发布策略 |
|---|---|---|
| P0 | 核心功能不可用、数据丢失风险、安全漏洞 | **Fail = 阻断发布** |
| P1 | 重要功能异常、用户体验严重受损 | **Fail = 默认阻断**，需用户确认接受风险 |
| P2 | 次要功能、美观问题、文档不完整 | Fail = 记录为后续改进，不阻断 |
